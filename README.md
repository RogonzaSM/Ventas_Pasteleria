# 🥐 Análisis de ventas en pastelería con Machine Learning  

## 📖 Introducción  
¿Vender más siempre significa ganar más?  
Este proyecto demuestra que no necesariamente. Analicé las ventas de una pastelería y descubrí que los gastos diarios pueden cambiar la historia: un día con muchas ventas puede ser menos rentable que otro con menos movimiento.  

---

## 📌 Planteamiento del problema  
Las pastelerías suelen medir su éxito por la cantidad de ventas diarias. Sin embargo, los costos de operación (ingredientes, personal, energía) pueden hacer que un día con muchas ventas no sea tan rentable como parece. El reto es entender cómo influyen los gastos en la rentabilidad y encontrar patrones que ayuden a tomar mejores decisiones.  

---

## 🎯 Objetivos  
- **General:** Analizar las ventas y gastos de una pastelería para evaluar la rentabilidad real y aplicar Machine Learning en la clasificación de días.  
- **Específicos:**  
  - Limpiar y preparar los datos de ventas y gastos con Python.  
  - Comparar ingresos vs. rentabilidad diaria.  
  - Identificar patrones de rentabilidad según el día de la semana.  
  - Entrenar un modelo de clasificación (Random Forest) para predecir si un día será “bueno”, “normal” o “flojo”.  

---

## 🧩 Hipótesis  
1. Los días con mayor volumen de ventas no siempre son los más rentables.  
2. Los costos diarios tienen un impacto directo en la ganancia neta.  
3. Es posible anticipar la rentabilidad de un día usando patrones históricos de ventas y gastos.  

---

## 📊 Metodología  
1. **Python (pandas, matplotlib, seaborn):** Limpieza y análisis exploratorio de datos.  
2. **Machine Learning (scikit-learn):**  
   - Modelos de clasificación para predecir rentabilidad.  
3. **Visualización:** Gráficos comparativos de ventas vs. rentabilidad por día de la semana.  

---

## 📓 Resultados  
- Se identificaron días con alto volumen de ventas pero baja rentabilidad.  
- El modelo predictivo clasificó jornadas como “buenas” o “malas” con base en ingresos y gastos.  
- Se obtuvieron insights estratégicos para decidir cuándo aplicar promociones y cómo optimizar recursos.  

---

## 🚀 Conclusión  
El análisis confirmó que **vender más no siempre significa ganar más**: los gastos diarios pueden reducir significativamente la rentabilidad. El modelo de Machine Learning logró clasificar los días en categorías de desempeño, ofreciendo una herramienta útil para decidir cuándo aplicar promociones o ajustar recursos.  
En resumen, este proyecto muestra cómo la analítica de datos puede transformar simples registros de ventas en **estrategias inteligentes para mejorar la rentabilidad de un negocio**.
