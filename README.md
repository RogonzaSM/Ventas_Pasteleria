Este análisis de ventas mensuales en una pastelería compara los ingresos obtenidos con la rentabilidad real (ventas – gastos diarios) en cada día de la semana. El objetivo es demostrar que vender mucho no siempre significa ganar más, ya que los costos pueden variar significativamente. Además, se implementó un modelo de Machine Learning para predecir si un día puede considerarse “bueno” o “malo” en términos de rentabilidad, aportando una visión más precisa y estratégica sobre el desempeño del negocio.
